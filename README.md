# EthernetCaptureApp：以太网数据包采集与分析工具

## 1. 简介
这是一个基于 **Python + Tkinter + Scapy** 的桌面工具，可用于：
- 选择本机网卡
- 设置单次捕获时长（秒）
- 捕获指定时间内的以太网/IP数据包
- 实时显示捕获数量与协议数量统计
- 对捕获到的数据进行分析（控制台统计 + 饼图 + 长度直方图）

> 说明：分析部分主要处理 **IPv4/IPv6** 数据包。

---

## 2. 功能特点
- 刷新网卡列表，界面以中文友好名称展示
- 后台线程抓包，避免阻塞 Tkinter 主界面
- 抓包完成后可点击“分析数据包”
- 协议统计与可视化：
  - 协议分布饼图
  - 数据包长度分布直方图
- 控制台输出：
  - `df.describe()` 基础统计
  - 按协议分组后的数量/均值/总和
